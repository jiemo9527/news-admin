# News Admin v2 设计

## 目标

把多来源新闻处理成「可信、去重、分好类、按重要度排序」的中文简报，并推送到各渠道。
大模型只做它擅长的事（理解、归纳、判断），所有输出都要经过程序校验；校验不过就重试或降级，绝不静默输出未校验的内容。

## 流水线

```
抓取 → 标准化 → 一级去重 → 逐篇分析 → 事件聚类 → 事件摘要 → 排序 → 发布/推送
fetch   normalize  dedupe     analyze    cluster    summarize   rank   publish
```

| 阶段 | 做什么 | 是否调用模型 |
|---|---|---|
| fetch | RSS 优先，正文用 trafilatura 抽取；记录来源健康度 | 否 |
| normalize | URL 规范化（去 utm、锚点、amp）、全角半角、空白、HTML 实体 | 否 |
| dedupe | 同一 URL / 同一正文（字符 3-gram 包含度 ≥0.8）只保留一篇，记录被合并的副本 | 否 |
| analyze | 每篇文章结构化抽取：中文标题、地区、主题、实体、关键事实、事件指纹 | LLM |
| cluster | 向量相似度 + 时间窗聚类；相似度落在模糊区间时交给 LLM 判定是否同一事件 | Embedding + LLM（少量） |
| summarize | 每个事件生成多来源摘要，句句带来源引用；报道冲突时显式说明 | LLM |
| rank | 规则打分（来源数、来源权重、新鲜度）+ LLM 影响力评级 | 否（复用 analyze 结果） |

## 原则

### 1. 分类：地区与主题是两个维度

旧版把「国内/国际」和「科技/金融」混在一个字段里，一条「中国芯片出口管制」只能二选一。v2 拆成：

- `region`：`domestic`（中国大陆）、`hk_mo_tw`（港澳台）、`international`、`global`（多国共同议题）
- `topic`：固定枚举（政治外交、军事安全、经济金融、产业公司、科技、社会民生、健康医药、环境能源、文体娱乐、其他），每个枚举在 Prompt 中给出定义和边界示例
- 只看新闻**内容**判断，不看来源是哪家媒体
- 模型给出 `confidence`（0-1），低于阈值的主题归为「其他」，避免硬分

### 2. 去重：三层，越往后越贵

1. **精确去重**：规范化 URL 相同 → 同一篇
2. **近重复**：正文字符 3-gram 包含度 ≥ 0.8 → 通稿转载，保留信息量最大的一篇，其余作为「转载来源」挂在下面。
   （最初用 SimHash，实测 RSS 短摘要上删改两个字汉明距离就到 6-8，不稳定，改为包含度）
3. **同一事件**：向量余弦相似度。向量的输入不是原文，而是 analyze 阶段产出的「中文标题 + 事件指纹 + 关键事实」——
   原文中英混杂，同一事件的中英文报道向量相距很远，归一化后才能聚到一起
   - ≥ 高阈值：直接合并
   - 位于模糊区间：交给 LLM 判定，定义写死：**参与方相同 + 行为相同 + 时间地点相同** 才算同一事件；后续进展算同一事件的「更新」，评论分析不与事实报道合并
   - < 低阈值：不同事件
   - 只在 48 小时时间窗内比较
4. **跨批次**：新事件与上一批次已发布事件比对；没有新事实就不重复推送，有新来源或新事实则标记为「更新」

### 3. 摘要：可追溯、不编造

- 只使用来源文本中出现的事实；不推测、不评论、不加「值得关注」类套话
- 每句话末尾必须带来源编号 `[1][2]`，编号必须对应实际输入的来源
- 句中数字必须能在**该句引用的来源**中找到（程序校验）。英文来源的月份名（July→7）、数字词（three→3）和中文小数字（三名→3）都算作证据
- 多家来源说法冲突时写明「A 称……，B 称……」，不擅自取舍
- 长度：标题 ≤ 32 字，摘要 2-4 句、≤ 180 字
- 校验失败 → 把错误回传给模型重试 1 次 → 仍失败则降级为主报道中通过数字校验的中文关键事实（没有则用原文首句），并在后台标记

### 4. 结构化输出

- 所有模型输出都由 Pydantic 模型定义，自动生成 JSON Schema，优先使用 `response_format=json_schema (strict)`；网关不支持时降级为 `json_object` + 本地校验
- 校验失败把 Pydantic 报错原文喂回模型重试（最多 2 次）
- 每次调用记录：阶段、模型、Prompt 版本、输入哈希、耗时、token 用量、是否命中缓存、是否降级
- 以「输入哈希 + Prompt 版本 + 模型」为键缓存结果，同一篇文章不会重复花钱

### 5. 排序

```
score = 影响力评级(1-5) × 2 + log2(1 + 独立来源数) × 1.5 + 新鲜度衰减 + 来源权重
```

影响力评级由 analyze 阶段给出，Prompt 中有明确评分标准（影响人群规模、是否首次发生、是否涉及政策/市场变动），并要求给出一句理由便于人工复核。

## 评测

`eval/` 下放人工标注的样本：

- 分类：每条标注 region/topic，统计准确率
- 去重：标注哪些文章属于同一事件，计算聚类的 Precision / Recall / F1
- 摘要：自动检查引用合法率、数字可溯源率；人工抽检忠实度

`python -m news_admin eval` 输出报告，用来比较不同模型、阈值和 Prompt 版本。
