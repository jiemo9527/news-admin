# 运维手册

## 常用命令

```bash
docker compose ps
docker compose logs --tail=100 news-admin
curl -fsS http://127.0.0.1:5080/healthz
docker compose restart news-admin
```

首次初始化日志含敏感随机密码。以后忘记密码请由其他管理员在用户管理中重置，或在维护窗口使用配置 `NEWS_ADMIN_PASSWORD` 指定管理员密码再重启；使用后去掉明文启动密码并在后台改密。

## 后台入口

- 概览：抓取计划、推送计划、运行记录；失败/中断运行可删除。
- 新闻来源：卡片、单源测试、编辑、启停、删除；推荐来源可重新添加。
- 系统设置：抓取时间窗、保留天数、模型/向量/阈值、密码。
- 数据管理（数据库小图标）：手动 ZIP 导出、恢复、清空；不自动备份。
- 用户管理：生成只读或管理员账号、复制初始凭据、停用/角色/改密/删除；访问记录只保存时间、IP、设备，不记录密码。

## 7×24 小时低速抓取

系统设置选择“7×24 小时内（低速模式）”。服务端会自动启用串行请求、3–6 秒间隔、403/429 中止来源。预计比普通模式慢，来源当前页没有历史时无法补齐。仍限制每源条数，不自动扩到几百条。不要把低速模式描述为保证不会风控。

## 问题排查

- 账号登录失败：确认用户启用、角色、密码；重置后旧会话失效。
- 无新闻：查看抓取窗口、来源是否启用、来源健康、过滤原因、模型调用错误。
- 容器启动失败：检查 `data/` 权限是否 10001，`config.env` 是否可写，5080 是否被占用。
- 缺图：外站没提供图片、图标过滤、下载失败等都会导致无图，新闻不因此丢弃。
- 不推送：检查独立的推送计划、渠道启用与凭据、是否有未成功发送的新结果。抓取计划不控制推送频率。
- 后台改模型重启后失效：不要在 Compose `environment` 覆盖模型字段，确保 `NEWS_ENV_PATH` 指向持久化目录。
- 403/429：停止对应来源本轮抓取，缩小数量/频率，不绕过 WAF。
- 时区：统一 Asia/Shanghai；容器 `TZ` 只作为系统工具一致性配置，业务时间使用 zoneinfo。

## 数据维护

手动导出 ZIP 后妥善离线保管。恢复包含敏感密钥，不能拿不可信 ZIP 覆盖生产数据。恢复支持当前 schema 包，跨旧版本需先升级并验证。恢复后需使用包内账号登录，所有旧会话失效。

清空不可撤销且不会自动备份。仅普通用户被删除，所有管理员保留。源、渠道、计划和模型设置保持。当前管理员密码校验仍必需，确认文字和弹窗按用户要求移除。
